## Before Requesting Support

Run:

```bash
rinc --version
```

Then:

```bash
rinc doctor
```

Include the following when reporting an issue:

- RINC version
- operating system
- system architecture
- available RAM
- feature or command being used
- exact user-facing error message

Do not send:

- passwords
- private keys
- API credentials
- confidential customer information
- proprietary model files
- unrelated personal data

## Installation Issues

For installation problems, also confirm:

- the release came from an official Realigns Inc. source
- the platform is supported by that release
- published integrity verification succeeded where applicable
- sufficient storage and normal user permissions are available
