# RINC Security Policy

Developed by **Realigns Inc.**

## Reporting a Security Issue

Please report suspected RINC security vulnerabilities privately to:

support@realignsinc.com

Please include:

- RINC version
- operating system
- system architecture
- relevant user-visible behavior
- steps needed to reproduce the issue
- expected behavior
- non-sensitive logs where useful

Do not include:

- passwords
- private keys
- API credentials
- personal data
- confidential customer information
- proprietary model weights
- unrelated confidential material

## Responsible Disclosure

Please do not publicly disclose an unresolved vulnerability before Realigns Inc. has had a reasonable opportunity to investigate and respond.

Submission of a security report does not authorize access to systems, accounts, infrastructure, devices, or data without permission.

## Scope

Security reports may concern supported RINC application behavior, user-facing interfaces, packaged releases, or installation behavior.

Protected Realigns Inc. implementation details, private build infrastructure, and proprietary internal architecture are not part of the public disclosure surface unless specifically authorized.

## No Automatic Bounty or Commercial Rights

Submitting a report does not create:

- a bounty entitlement
- an employment relationship
- a consulting agreement
- commercial-use rights
- authorization to test systems without permission
